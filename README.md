# Portfolio

My personal portfolio site: projects, skills, resume and contact.

**Live:** https://portfolio-eight-silk-85.vercel.app

Built with Next.js (App Router), TypeScript, Tailwind CSS and Framer Motion, deployed on Vercel.
All content comes from one data file, `app/data/resume.ts`, so updating the site means editing that file.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
